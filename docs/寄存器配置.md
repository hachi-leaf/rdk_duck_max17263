# MAX17263 寄存器配置参考

在 MCU 上自己实现（不用 Linux 驱动）时参考。

- 总线：I2C，地址 `0x36`
- 采样电阻：10 mΩ
- 16 位寄存器，word 读写；`0x4B` / `0x37` / `0xDB` / `0x64` 是奇数地址，用 word 模式

---

## 一、常量

```c
#define MAX17263_I2C_ADDR   0x36

/* 电池 */
#define DESIGNCAP           0x05DC   /* 1500 mAh, LSB = 1 mAh */
#define MODELCFG_REFRESH    0x8000   /* ModelCfg bit15, 触发刷新 */

/* LED */
#define LEDCFG1             0x80E8   /* 常亮 + NBARS=8 + 无灰阶 */
#define LEDCFG2             0x004F   /* 亮度15 + 低电闪 */
#define LEDCFG3             0xC000   /* FullSpd + 正常模式 */
#define CUSTLED             0x0000
```

---

## 二、上电初始化顺序

**MAX17263 没有 NVM，断电后寄存器回默认值，每次上电都要重写。**

| 序 | 寄存器 | 地址 | 写入 | 频率 |
|---|---|---|---|---|
| 1 | DesignCap | `0x18` | `0x05DC` | 每次上电 |
| 2 | ModelCfg | `0xDB` | 读出后 `\| 0x8000` | 换电池 / 改容量时 |
| 3 | LEDCfg3 | `0x37` | `0xC000` | 每次上电 |
| 4 | LEDCfg2 | `0x4B` | `0x004F` | 每次上电 |
| 5 | LEDCfg1 | `0x40` | `0x80E8` | 每次上电 |
| 6 | CustLED | `0x64` | `0x0000` | 每次上电 |

顺序不可颠倒：DesignCap 必须在 ModelCfg 刷新之前写。

```sh
i2cset -y 5 0x36 0x18 0x05DC w        # DesignCap 1500mAh
i2cset -y 5 0x36 0xdb 0x8408 w        # ModelCfg 刷新（0x0408 | 0x8000）
i2cset -y 5 0x36 0x37 0xC000 w        # LEDCfg3
i2cset -y 5 0x36 0x4b 0x004F w        # LEDCfg2
i2cset -y 5 0x36 0x40 0x80E8 w        # LEDCfg1
```

**刷新时机**：读 `FullCapRep(0x10)` 与 `DesignCap(0x18)`，不相等时刷新。
`ModelCfg` 的 bit15 写完自动清零，因此刷新不要用回读值判断成败，
改判 `FullCapRep` 是否变成等于 `DesignCap`。

## 三、寄存器字段

### DesignCap (0x18)

LSB = 1 mAh。芯片默认 `0x0BB8` = 3000 mAh。
`mAh = mWh ÷ 3.7`，例如 5550 mWh → 1500 mAh。

### ModelCfg (0xDB)

`D15 = Refresh`：写 1 触发一次电量计复位，FullCap 改为等于 DesignCap，SOC 重算，写完自动清零。

### LEDCfg1 (0x40) = 0x80E8

| 位 | 字段 | 值 | 含义 |
|---|---|---|---|
| D15:D13 | LEDTimer | 100 | 2.7 s（常亮模式不用） |
| D12:D10 | AniStep | 000 | 不做动画 |
| D9:D8 | AniMd | 00 | 正常 |
| **D7:D6** | **LEDMd** | **11** | **常亮** |
| D5 | LChg | 1 | 充电时常亮 |
| D4 | GrEn | **0** | **无灰阶**，余数四舍五入 |
| **D3:D0** | **NBARS** | **8** | **总共 8 格** |

`NBARS` 是总格数，芯片按 RepSOC 自动决定点亮几格。

**四种 LEDMd**：`00` 关 / `01` 按键+定时 / `10` 按住才亮 / `11` 常亮
**四种 AniMd**：`00` 正常 / `01` 逐格填充 / `10` 呼吸 / `11` 填充+呼吸

### LEDCfg2 (0x4B) = 0x004F

| 位 | 字段 | 值 | 含义 |
|---|---|---|---|
| D8 | EnAutoLEDCnt | **0** | 关闭 LED 数量自动检测（本板必须为 0）|
| D6 | EBlink | 1 | 低电时最低一格闪 |
| D4:D0 | Brightness | 15 | 亮度 15/31 |

### LEDCfg3 (0x37) = 0xC000

| 位 | 字段 | 值 | 含义 |
|---|---|---|---|
| D15 | FullSpd | 1 | 175 ms 刷新（0 = 700 ms） |
| D14 | DNC | 1 | 芯片自动计算，写入后回读值可能不同 |
| D13 | CustLEDCtrl | 0 | 由 LEDCfg1/2 管理（正常模式） |

## 四、读取数据

| 寄存器 | 名称 | LSB | 说明 |
|---|---|---|---|
| `0x06` | RepSOC | 1/256 % | 电量 |
| `0x09` | VCell | 78.125 uV | 电压 |
| `0x0A` | Current | 156.25 uA | 有符号，正=充电，负=放电 |
| `0x08` | Temp | 1/256 °C | 有符号 |
| `0x10` | FullCapRep | 1 mAh | 满充容量 |
| `0x18` | DesignCap | 1 mAh | 设计容量 |

```c
soc_pct = read(0x06) / 256.0;
volt_V  = read(0x09) * 78.125e-6;
curr_mA = (int16_t)read(0x0A) * 156.25e-3;
```

电流由 10 mΩ 采样电阻测得：1 mV ↔ 100 mA，分辨率 156.25 µA。
库仑计对电流积分得到电量。

## 五、显示风格切换

### LEDCfg1 (0x40)

| 效果 | 值 |
|---|---|
| **常亮 + 无灰阶（默认）** | **0x80E8** |
| 常亮 + 灰阶 | 0x80F8 |
| 按键 + 10 s + 直接亮 | 0xE078 |
| 按键 + 10 s + 逐格填充 | 0xE578 |
| 按键 + 10 s + 呼吸 | 0xE2B8 |
| 按键 + 2.7 s + 直接亮 | 0x8078 |

### LEDCfg2 (0x4B)

| 效果 | 值 |
|---|---|
| **亮度 15 + 低电闪（默认）** | **0x004F** |
| 亮度 8 + 低电闪 | 0x0048 |
| 亮度 24 + 低电闪 | 0x0058 |
| 去掉低电闪 | 0x000F |

## 六、逐颗点亮 LED（CustLED）

```sh
i2cset -y 5 0x36 0x37 0xE000 w     # CustLEDCtrl = 1
i2cset -y 5 0x36 0x64 0x001 w      # 只点 LED0（1<<n，共 12 颗）
i2cset -y 5 0x36 0x64 0x0000 w
i2cset -y 5 0x36 0x37 0xC000 w     # 恢复 LEDCfg 管理
```
